# yt_search — банк тем для YouTube по данным конкурентов

Анализ ниши **«семейные драмы / истории из жизни»** на английском, испанском (Испания) и немецком.
Ниша «предсказания» отключена: её запросы лежат в `DISABLED_NICHES` в `config.py`, чтобы вернуть — перенесите в `NICHES`.
Только длинные ролики (Shorts отбрасываются).

## Что делает

1. **`yt_research.py`** — поиск по запросам из `config.py`, выбор профильных конкурентов
   (каналы, которые встречаются по нескольким запросам ниши на нужном языке), выгрузка их каталогов,
   расчёт **выбросов**: ролик набрал в N раз больше медианы своего канала.
2. **`comments.py`** — комментарии под выбросами: просьбы зрителей («part 2», «haz uno de…»), топ по лайкам.
3. **`build_bank.py`** — собирает **банк тем** `output/bank_tem_<дата>.xlsx`:
   - `Темы_семейные` — кластеры тем, примеры хитов, новые углы подачи;
   - `Формулы_названий`, `Превью`, `Комментарии_инсайты` — что работает в названиях, превью, комментариях;
   - `Конкуренты`, `Выбросы_конкурентов`, `Хиты_малых_каналов`, `Комментарии_топ` — сырые данные со ссылками.

Кластеры тем и выводы по превью/комментариям написаны вручную (Claude) в `build_bank.py` по результатам прогона —
их нужно пересматривать при каждом новом прогоне.

## Запуск

```bash
pip install -r requirements.txt
python3 yt_research.py --check      # проверить ключ
python3 yt_research.py              # сбор (~6 500 единиц квоты)
python3 comments.py 15              # комментарии: по 15 роликов на нишу×язык (~90 единиц)
python3 build_bank.py               # банк тем
```

Ключ YouTube Data API v3:
- в облачной сессии Claude — Network secret на `www.googleapis.com`, заголовок `X-Goog-Api-Key`, без префикса;
- локально — переменная окружения `YOUTUBE_API_KEY`.

Ответы API кэшируются в `cache/` (не коммитится): повторный запуск в тот же день квоту не тратит.
При поминутном лимите скрипт сам ждёт и повторяет.

Режимы экономии квоты: `--lite` (меньше каналов), `--cached-search-only` (не делать новых поисков).

## Квота

| Шаг | Единиц |
|---|---|
| Поиск: 29 запросов × 2 длительности | ~5 800 |
| Каталоги 45 каналов | ~500–800 |
| Комментарии 45 роликов | ~45 |

Дневной лимит ключа — 10 000.

## Структура

```
config.py         ниши, запросы, пороги
yt_research.py    сбор и расчёт выбросов
comments.py       комментарии
build_bank.py     сборка банка тем (+ ручные кластеры)
output/           результаты прогонов (xlsx/csv)
thumbs/           сетки превью: хиты (TOP) и слабые ролики тех же каналов (LOW)
```
